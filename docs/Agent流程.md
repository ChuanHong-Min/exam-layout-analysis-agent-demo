# Agent 流程

## 1. OCR 几何主干

从 PDF 页面或输入试卷图像获取文字行、公式、图片区域、polygon 和索引，形成后续阶段统一使用的 block 列表。Layout 检测与 OCR 负责“看见什么、在哪里”，不负责决定题目语义边界。

## 2. VLM 语义聚合

将原图与 OCR block 列表一起提供给 Qwen-VL 或 Gemini，要求模型输出：

- block 属于哪道题；
- 主干题与子题的层级关系；
- 附图属于哪道题；
- 作答区的空白 polygon；
- 题型分类。

模型不重写 OCR 文本，也不作为最终坐标来源。

## 3. 几何执行器

对同题 OCR block polygon 和预测作答区 polygon 做 convex hull 合并，保证题目区域完整连通；再使用 minAreaRect 做旋转矩形拟合，得到统一的区域表达。

## 4. 质量门限与回退

每个候选题目按以下四个维度评分：

| 维度 | 权重 |
| --- | ---: |
| 文本覆盖率 | 40 |
| 几何稳定性 | 30 |
| 区域合理性 | 20 |
| 版面一致性 | 10 |

总分低于 `85` 时触发 fallback，重新进行语义聚合，避免直接把不可靠的大模型结果送入后续系统。

## 5. 输出示例

公开版只应使用虚构或自制样例，结构可以保持为：

```json
{
  "type": "single_choice",
  "id": "q_001",
  "polygon": [[12, 20], [480, 20], [480, 220], [12, 220]],
  "answers": [],
  "figures": []
}
```

上面的坐标和内容仅为结构示例，不代表内部真实样本。

# 版式分析流程伪代码

以下内容仅描述流程思路，不包含可运行代码、真实接口、生产 Prompt、模型配置或源数据位置。

## OCR Block Extraction

```text
输入：单页试卷图像
输出：标准化 OCR block 列表

读取图像尺寸与页面方向
调用 OCR 能力获取文字、公式、表格、图片区域和原始 polygon
过滤置信度过低且无法参与版式判断的噪声 block
统一坐标系，将 polygon、bbox、文本类型和阅读顺序写入 block
按纵向位置、横向栏位和邻近关系建立候选行、候选段落、候选图片块
标记可能的题号、子题号、选项、作答区、图注和页眉页脚
返回可追溯的 block 列表
```

## VLM Semantic Grouping

```text
输入：页面缩略图、OCR block 摘要、候选阅读顺序
输出：题目语义分组建议

将 OCR block 压缩为只含编号、文本摘要、类型和归一化坐标的观察列表
要求 VLM 判断每个 block 属于题干、子题、附图、选项、解析无关区域或作答区
要求 VLM 给出主题与子题层级、附图归属、跨栏延续关系和不确定项
禁止 VLM 改写 OCR 文本或生成缺失坐标
对 VLM 输出进行结构检查：题号连续性、block 引用存在性、重复归属、空分组
保留不确定分组，交给后续几何融合和质量评分处理
```

## Geometry Fusion

```text
输入：OCR block 列表、VLM 分组建议、页面结构线索
输出：每道题的候选 polygon

按语义分组收集题干、子题、选项、附图和作答区 block
对每组 block 的 polygon 计算覆盖外轮廓
结合栏位边界、阅读顺序和相邻题目间距修正过宽或过窄的区域
若题目跨栏或跨页片段，拆分为多个局部 polygon 并保留同一题目 id
对附图和作答区使用距离、方向、题号锚点和重叠关系确认归属
输出题目 polygon、子题 polygon、答案区 polygon、附图 polygon 和来源 block id
```

## Quality Scoring

```text
输入：候选题目结构、OCR block、页面尺寸
输出：质量分与问题标签

计算覆盖分：题目相关 block 是否被 polygon 覆盖，是否包含过多无关 block
计算稳定分：题号顺序、阅读方向、栏位顺序和相邻题目边界是否稳定
计算合理分：polygon 面积、长宽比、留白比例和作答区位置是否符合版式常识
计算一致分：VLM 分组、OCR 类型、几何邻近关系是否互相支持
汇总四项分数，记录低分原因和需要重聚合的题目 id
若总分达到阈值，输出候选结构
若总分低于阈值，进入 fallback
```

## Fallback

```text
输入：低质量候选结构、问题标签、原始 OCR block
输出：修正后的候选结构或人工复核标记

定位低分来源：漏覆盖、误包含、跨栏错误、附图错配、作答区错配或题号断裂
按问题类型选择更保守的重聚合策略
若题号断裂，以题号锚点和阅读顺序重新切分题目边界
若附图错配，以最近题干、图注文本和垂直重叠关系重新绑定
若作答区错配，以空白区域、横线区域和相邻题目边界重新推断
重新计算 polygon 与质量分
若仍低于阈值，输出人工复核标记并保留全部可追溯 block id
```

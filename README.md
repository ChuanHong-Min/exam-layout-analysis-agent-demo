# 试卷版式分析 Agent：OCR + VLM + 几何质量控制

> 脱敏技术展示 / 项目案例说明
>
> 本仓库用于展示试卷版式分析 Agent 的方案设计、几何质量控制思路和脱敏可视化材料。公开版本不包含内部源代码、OCR 服务、原始数据、模型权重或生产配置。

## 项目简介

项目面向词典笔拍照答题场景，目标是从试卷图像中定位每道题的完整区域，包括题干、附图和作答区，并输出结构化 polygon，供后续答题辅助或题库处理使用。

纯 OCR 方案能够提供文字和几何坐标，但难以稳定判断跨栏、跨列、图文穿插关系，也容易把作答区空白误判为题目间距。因此方案采用 OCR 与视觉语言模型协同，再用确定性几何方法收敛输出。

## 个人职责

- 设计 OCR + VLM 协同的多阶段 Agent 流程；
- 负责 block 归属、主子题层级、附图归属和作答区 polygon 的提示词迭代；
- 设计 convex hull / 旋转矩形几何融合和四维 QA 评分；
- 让大模型只做语义判断，文字与坐标尽量来自可追溯的 OCR / 几何结果。

## 关键结果

- 在 100 张评测集上完成方案效果验证；
- 四维质量评分低于 `85` 时自动触发 fallback 重新聚合；
- 输出包含 `type`、`id`、`polygon`、`answers`、`figures` 等字段的结构化 JSON；
- 覆盖主干题 / 子题层级、附图归属、作答区归属和题型分类。

## 技术路线

```text
原始试卷图像
    ↓
OCR：文本 / 公式 / 图片区域及 polygon
    ↓
VLM：题目归属 / 主子题层级 / 作答区语义判断
    ↓
几何融合：convex hull + minAreaRect
    ↓
四维 QA：覆盖 / 稳定 / 合理 / 一致
    ↓
合格输出或 fallback 重聚合
```
